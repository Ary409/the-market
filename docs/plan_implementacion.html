Plan de implementación por fases del sistema de inventario y ventas para mini supermercados

Roles: Admin Vendedor
Fase 1 Base del proyecto · Backend + Base de datos ~2 semanas

1.1 · Estructura del proyecto

Crear carpetas, entorno virtual Python, instalar FastAPI, Uvicorn, SQLite. Configurar .gitignore y README.

1.2 · Modelos de base de datos

Tablas: usuarios, roles, categorias, proveedores, productos, ventas, detalle_venta, movimientos_stock, caja.

1.3 · Autenticación y roles

Login con JWT. Middleware de roles: Admin (acceso total), Vendedor (solo POS e inventario lectura).

AdminVendedor

1.4 · Endpoints base CRUD

CRUD completo: /productos, /categorias, /proveedores, /usuarios. Con paginación, filtros y búsqueda por código de barras.

Admin
Fase 2 Módulo de inventario ~1.5 semanas

2.1 · Gestión de stock

Entradas y salidas de inventario. Registro de movimientos con motivo, cantidad, usuario que realizó el ajuste.

Admin

2.2 · Alertas de stock mínimo

Endpoint que retorna productos bajo el stock mínimo definido. Se consulta al iniciar sesión y en el dashboard.

AdminVendedor

2.3 · Módulo de compras

Órdenes de compra a proveedores. Registro de facturas, actualización automática de stock al recibir mercadería.

Admin

2.4 · Búsqueda por código de barras

Endpoint optimizado GET /productos/barcode/{codigo} que retorna producto completo en menos de 100ms.

AdminVendedor
Fase 3 Módulo de ventas y caja (POS) ~2 semanas

3.1 · Registro de ventas

Crear venta con múltiples productos, calcular total, descontar stock, registrar método de pago (efectivo/tarjeta).

VendedorAdmin

3.2 · Recibos y comprobantes

Generar recibo en formato JSON listo para imprimir en impresora térmica (58mm/80mm) o mostrar en pantalla.

Vendedor

3.3 · Apertura y cierre de caja

Apertura de caja con monto inicial. Cierre con conteo de efectivo, diferencias, resumen del día por método de pago.

AdminVendedor

3.4 · Devoluciones

Anular ventas o devolver productos individuales. Reponer stock automáticamente. Solo admin puede anular.

Admin
Fase 4 Reportes y dashboard (Admin) ~1.5 semanas

4.1 · Reportes de ventas

Ventas por día/semana/mes/rango, por vendedor, por método de pago. Exportar a CSV.

Admin

4.2 · Reportes de productos

Top productos más vendidos, productos sin movimiento, ganancia bruta por producto y categoría.

Admin

4.3 · Dashboard resumen

Endpoint único GET /dashboard que retorna todo lo necesario para la pantalla principal del admin en una sola llamada.

Admin

4.4 · Gestión de usuarios

Admin crea/edita/desactiva vendedores. Historial de acciones por usuario. Cambio de contraseña.

Admin
Fase 5 App desktop (Windows) · Electron + React ~3 semanas

5.1 · Proyecto Electron base

Setup con Electron + React + Vite. Configuración de la URL del servidor, pantalla de login, sidebar de navegación.

5.2 · Pantallas admin

Dashboard, inventario, compras, proveedores, reportes, gestión de usuarios. Tablas con filtros y paginación.

Admin

5.3 · POS pantalla vendedor

Interfaz de punto de venta: buscar producto, agregar al carrito, cobrar. Diseño optimizado para pantalla táctil.

Vendedor

5.4 · Empaquetado como .exe

Configurar electron-builder para generar instalador .exe para Windows. Con ícono del negocio personalizable.

Fase 6 App móvil · React Native + Expo ~2.5 semanas

6.1 · Proyecto Expo base

Setup con Expo + React Navigation. Login, configuración de IP del servidor, almacenamiento del token.

6.2 · Escáner de código de barras

Leer código de barras con la cámara usando Vision Camera + MLKit. Buscar producto y agregarlo al carrito automáticamente.

VendedorAdmin

6.3 · POS móvil

Pantalla de venta rápida: carrito, cobrar, mostrar resumen de recibo. Optimizada para uso con una mano.

Vendedor

6.4 · Alertas y consultas rápidas

Pantalla de alertas: stock bajo y por vencer. Consulta rápida de stock de un producto escaneando.

Admin
Fase 7 Integración final · pruebas y despliegue ~1 semana

7.1 · Script de instalación

Script que instala Python, dependencias y corre el servidor como servicio de Windows al iniciar la PC.

7.2 · Backup automático

Script que hace copia del archivo SQLite diariamente a una carpeta local o USB. Con límite de copias guardadas.

7.3 · Pruebas del flujo completo

Checklist de pruebas: login, venta completa, cierre de caja, alertas, backup, acceso por roles.

7.4 · Manual de usuario

Manual rápido para el dueño del negocio y para los vendedores. Operaciones más comunes paso a paso.
